# Portal Modular de Investigación y Posgrado

Frontend desacoplado para incrustar de forma modular en **Google Sites** mediante **GitHub Pages**, conectado a una única API en **Google Apps Script**.

## Módulos publicados en GitHub Pages

- `/sesiones.html` — Sesiones en vivo de Zoom y Comunicados oficiales.
- `/materias.html` — Aula por asignatura, materiales en Google Drive y buzón privado de trabajos.
- `/calificaciones.html` — Consulta homologada de Kárdex y promedios.
- `/pagos.html` — Estado de cuenta y buzón privado de comprobantes (vouchers).
- `/admin.html` — Consola administrativa para Coordinación de Posgrado.

> **Seguridad:** Este repositorio contiene únicamente la interfaz visual y scripts cliente. Ninguna credencial, lista de alumnos, calificación, enlace de Zoom ni carpeta de Google Drive se almacena aquí.
